# 天气图标库 (Weather Icons)

本目录包含所有与天气相关的 SVG 图标文件，整理自 `@mdi/svg` 官方图标库。

## 目录结构

```
weather/
├── img/                    # 天气图标 SVG 文件
│   ├── weather-*.svg       # 天气主图标
│   ├── sun-*.svg           # 太阳相关图标
│   ├── cloud*.svg          # 云朵图标
│   ├── lightning*.svg      # 闪电图标
│   ├── snowflake*.svg      # 雪花图标
│   ├── thermometer*.svg    # 温度计图标
│   ├── umbrella*.svg       # 雨伞图标
│   ├── wind*.svg           # 风力图标
│   └── ...
└── about-weather-ico.md    # 本文档
```

## 使用方法

### React/Vue 中使用

```tsx
import React from 'react';
import { ReactComponent as WeatherSunny } from './img/weather/weather-sunny.svg';

function WeatherIcon() {
  return <WeatherSunny width={24} height={24} />;
}
```

```vue
<template>
  <img src="./img/weather/weather-sunny.svg" alt="晴天" width="24" height="24" />
</template>
```

### HTML 中使用

```html
<img src="./img/weather/weather-sunny.svg" alt="晴天" width="24" height="24" />
```

### 作为 CSS 背景

```css
.icon-sunny {
  background-image: url('./img/weather/weather-sunny.svg');
  background-size: contain;
  background-repeat: no-repeat;
}
```
