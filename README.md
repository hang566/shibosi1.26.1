## 介绍
市舶司是一个功能丰富的游览器启动页，存在多搜索引擎搜索，元搜索引擎，昨日晚报，互联网信息搜罗器等，目的是为了减轻用户上网成本，使用最少的的时间获得最正确的信息和资讯。
 <br> 
市舶司将会过滤错误的信息，标记文章立场等，未来甚至会对所有公开的新闻进行实时追踪和分析。

## 了解现在的功能
- ### 指令
  项目内置了“/go”跳转，“/s”切换搜索引擎和“/email”通过api打开电子邮箱，其中“/go”随着搜索框都升级将会淘汰，因为目前无需键入“/go”也可以跳转。
- ### 搜索引擎
  项目通过内置“bing”，“baidu”，“Google”和“Duckduckgo”，通过Go语言进行抓取，清洗，展示等，除此之外加入了特色功能，你可以在搜索引擎中直接收藏，你无需再次搜索。
- ### 游戏中心
  为了<del>严重拖慢</del>让用户可以适当放松心情，加入了一些小游戏。如“大富翁”、“井字旗”、“oc”等，以调整用户心情。
- ### 收罗器（使用画中画api，部分游览器不适配）
  互联网公司总是在打造消息孤岛，你需要的资料可能分散在lililili，知不乎，小绿书，掘银等平台，所以txt，md，word等可能需要设计排版，分类等，但是你使用市舶司，启动服务，游览器弹出画中画悬浮在所有窗口之上不需要在屏幕上扒拉来扒拉去，你可以将文本，URL等内容拖入或复制进去（富文本可能携带危险内容，暂不支持），这将保存到市舶司。
- ### 昨日晚报
  通过RSS技术在多个新闻网站获得新闻，通过简单的算法对新闻进行立场标记，交叉验证分析新闻可信度等。
- ### 积分页面（积分不为货币，不得在社区流动）
  展示当前积分，提示如何获得积分，积分变更记录和在华合规提示。
